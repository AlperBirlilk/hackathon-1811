Kullanım

Her isteğe başlık ekleyin:

Authorization: Bearer <token>

Örnek:

curl -H "Authorization: Bearer $PORTAL_API_TOKEN" {{ api_base_url }}/api/me

Yanıtlar JSON'dur. Hatalar {"error": {"code", "message"}} biçiminde döner. API salt okunurdur; yalnızca GET desteklenir.
